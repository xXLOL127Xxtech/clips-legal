Privacy Policy

Last updated: 18 November 2026

1. About this tool

This is a personal tool operated by a single individual (the "Operator"). It analyzes publicly available videos and publishes clips to social media accounts owned and controlled by the Operator. It is not offered to the public and has no user registration.

2. Data we process

  • Public video content that the Operator chooses to analyze, processed to create clips.
  • OAuth access and refresh tokens for the Operator's own YouTube, TikTok, Instagram and Facebook accounts, used only to publish clips to those accounts.
  • Basic account identifiers and publishing status returned by those platforms' APIs for the Operator's own accounts.

We do not collect personal data from visitors to this website. This site uses no cookies, analytics, advertising or tracking.

3. Storage and security

OAuth tokens are stored only on the Operator's own server and are never shared with, disclosed to, or sold to third parties. Access is limited to the Operator.

4. Sharing and sale of data

We do not sell, rent, or transfer data to third parties. We do not sell data of any third party. Data is exchanged only with the platform APIs (YouTube / Google, TikTok, Meta) as needed to publish content to the Operator's own accounts.

5. Google API Services

Use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

6. Retention and deletion

Tokens and related data are kept only as long as needed to operate the tool. You may revoke access at any time in your platform's security settings. To request deletion of any data, contact us and we will delete it on request.

7. Changes

We may update this policy; the date above shows the latest revision.
